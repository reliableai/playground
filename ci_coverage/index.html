Standard deviation, standard error, and the 95% CI

One eval gives you three numbers that people put on charts as “interval bars”. Only one of them is about your estimate, and none of them is a probability about the accuracy. Pick a true accuracy and a test-set size, run the eval once, then run it hundreds of times and count how often the 95% interval actually catches the truth.

How to read and interact with this page
  1. Set the world. Choose the true accuracy and N. In real evals the truth is unknown; here you fix it so you can check what the intervals do.
  2. Run one eval. The dots are the N outcomes. The three panels show the SD of those 0/1 outcomes, the SE of the estimate, and the 95% interval from this single run, with the truth marked as inside or not.
  3. Compare the sizes. The table holds p̂ fixed and shows what happens at N = 5, 100 and 10,000: the SD does not move, the SE falls with √N, and the interval narrows.
  4. Repeat the eval. Choose how many repeats and press “Run X evals”. Left: each interval as a bar, magenta when it misses the dashed truth, with the hit count against the 95% target. Right: the histogram of observed accuracies, whose spread is what the SE predicts.
  5. Start with 20, then go to 10,000. With 20 repeats the coverage wobbles; with thousands it settles near 95%. That is the only promise a confidence interval makes.
  6. Switch to Wald at N = 5. The textbook interval runs past 100% and catches the truth far less than 95% of the time. Wilson does not.

The world we pretend to know

In real life the true accuracy is unknown; that is the whole point. Here we set it, so we can check what the intervals do.

Run the eval once: three numbers

—

Standard deviation

Spread of the individual 0/1 outcomes.

SD = √( p̂ (1 − p̂) )

—the same whether N is 5 or 10,000

It tells you nothing you did not already know from p̂: a binary outcome has no spread of its own to report. An SD bar on an accuracy chart is almost always a mistake, and more data never shrinks it.

Standard error

How much p̂ would scatter if you re-ran the whole eval with N fresh examples.

SE = SD / √N

—shrinks with √N: 100× the data buys 10× the precision

A statement about the estimate, not about individual answers. The section below makes it visible: the SE is the standard deviation of the observed accuracies across repeated evals.

95% confidence interval

Wilson interval.

p̂ ± 1.96 · SE

—from this one eval

Not: “95% probability the true accuracy is in here”. But: “repeat the eval; 95% of the intervals built this way catch the true accuracy.” The 95% is a property of the recipe, not of this interval.

This is the sampling distribution. The SE from a single eval, —, is a prediction of the spread you see here. With enough repeats the two agree; that is what “standard error” means.

Notes

Wald vs. Wilson

The textbook interval p̂ ± 1.96·SE (Wald) assumes the sampling distribution of p̂ is normal around p̂, which is fine at N = 100 and breaks at small N or extreme accuracy: for 4 out of 5 it runs from 45% to 115%, and its coverage falls well below 95%. The Wilson interval instead solves for the accuracies that would make the observed p̂ plausible, stays inside 0 to 100%, and keeps its coverage honest. Switch the method above with N = 5 and compare the coverage counts.

Three misreadings of a 95% CI
  • “There is a 95% probability the true accuracy is in this interval.” The truth is a fixed number; it is either in there or it is not. The 95% describes how often the recipe succeeds.
  • “95% of runs will land in this range.” That treats the CI like an SD-style spread of outcomes. It is not.
  • “Two overlapping CIs mean no significant difference.” Overlap is a much more conservative test than it looks.

If you want a sentence that starts “the probability that the accuracy is above 90% is…”, you need a belief, not a confidence interval: see the Estimating Accuracy playground.
