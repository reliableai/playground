Inflated Estimates in Multiple Hypotheses Testing

Try N variants on one test set, keep the best. How inflated is its score? "You didn't peek at the data. You're still fooled."
What is this playground about? (click to expand)

The scenario: you are building a few-shot LLM classifier that routes support tickets to one of five teams. You write N prompt variants, score every one of them on the same test set of n tickets on one metric of interest, accuracy, and keep the variant with the best score. That is what everybody does, and it is the right way to pick. The trap is in what you then report.

The catch: every score is the true accuracy plus sampling noise. If you measure one variant, its score is unbiased. If you measure N and keep the highest, you kept the one whose noise happened to be the most positive. The winner's score is inflated, and the inflation grows with N and shrinks only with √n. You never looked at the test data, you did nothing wrong, and you are still fooled. This is the Select goal from the lesson, and its bias is called the winner's curse.

How much? If the per-ticket noise has standard deviation σ, the winner sits about (σ/√n) × √(2 ln N) above the truth on average (the expected maximum of N normal draws). With accuracy near 82%, n = 200 and N = 10, that is about +4.2 points.

The fix: select on one set of tickets, then report the winner's score from a different one, tickets it has never seen. Or shrink the winner's estimate toward the group, by an amount you can compute from the leaderboard itself (second tab).

Reality: N similar variants, ranked by how good they truly are, based on accuracy.
0 = all exactly equal. Otherwise the true accuracies are spread evenly from V1 (best) down to VN, around 82%.

How this is computed

Each variant gets a posterior on its true accuracy from its own count: Beta(correct + 1, wrong + 1). Probability of being best: draw one true accuracy per variant from these posteriors, note which is highest, repeat 20,000 times; the share of draws each variant wins is its probability. Shrinkage: the N variants are attempts at the same task, so their true accuracies cluster. From the spread of the measured scores we estimate how much of that spread is real (between-variant variance τ²) and how much is noise; each score is then pulled toward the group mean by the factor noise / (noise + τ²). The winner, being the most extreme, is pulled the most. The gap between its measured score and its shrunk estimate is the expected inflation. When the scores are all within noise of each other, τ² is about zero and the winner is pulled all the way to the group mean, which is the honest answer.
